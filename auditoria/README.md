# Auditoria - CercaYa

Esta carpeta contiene los documentos de auditoria tecnica, seguridad, remediacion y producto de CercaYa.

## Lectura recomendada

1. `estado_actual_release.md`  
   Fuente principal para saber el estado vigente del proyecto antes de beta o produccion.

2. `auditoria_funcional_producto.md`  
   Auditoria de alcance, objetivo de producto, flujos criticos y pruebas funcionales faltantes.

3. `estado_remediacion.md`  
   Seguimiento historico de remediacion de seguridad y hardening backend.

4. `checklist_remediacion.md`  
   Checklist historico de acciones tecnicas pendientes y completadas.

5. `security_findings.md`  
   Hallazgos originales de seguridad. Contiene evidencias sensibles historicas; tratar como documento interno.

6. `informe_auditoria.md` y `resumen_ejecutivo.md`  
   Auditoria original del 2026-04-29.

7. `INFORME_FINAL_AUDITORIA.md` y `RESUMEN_CAMBIOS_2026-04-30.md`  
   Documentos de cierre/cambios historicos.

## Estado de los documentos

| Documento | Tipo | Estado |
|---|---|---|
| `estado_actual_release.md` | Release / decision | Vigente |
| `auditoria_funcional_producto.md` | Producto / QA | Vigente |
| `estado_remediacion.md` | Seguridad / remediacion | Historico, aun util |
| `checklist_remediacion.md` | Seguridad / tareas | Historico, aun util |
| `security_findings.md` | Seguridad | Historico/confidencial |
| `informe_auditoria.md` | Auditoria original | Historico |
| `resumen_ejecutivo.md` | Resumen original | Historico |
| `INFORME_FINAL_AUDITORIA.md` | Cierre historico | Historico |
| `RESUMEN_CAMBIOS_2026-04-30.md` | Cambios historicos | Historico |

## Nota importante

Algunos documentos antiguos pueden contener texto con encoding roto o estados ya superados. Para decisiones actuales, usar primero `estado_actual_release.md`.
