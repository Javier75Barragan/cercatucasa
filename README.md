# CercaYa

CercaYa es una plataforma hiperlocal para conectar personas con vendedores, comercios, servicios e incidentes cercanos en tiempo real.

La documentacion principal del proyecto esta consolidada en:

[DOCUMENTACION_CERCAYA.md](./DOCUMENTACION_CERCAYA.md)

Ese archivo concentra:

- Vision y objetivos.
- Alcance de la app.
- Roles de usuario.
- Funcionalidades principales.
- Arquitectura backend/frontend.
- API.
- Seguridad.
- Auditoria.
- Testing.
- UX/producto.
- Base de datos y migraciones.
- Despliegue.
- Estado actual por categoria.
- Roadmap.
- Criterios para beta y produccion.

Los documentos anteriores se mantienen como historial y referencia, pero la fuente principal para entender el proyecto es `DOCUMENTACION_CERCAYA.md`.
